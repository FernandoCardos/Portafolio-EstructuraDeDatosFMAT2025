# Estructuras de Datos y Algoritmos: Proyectos del Curso

Este repositorio contiene todas las Actividades de Desarrollo Autogestivo (ADAs) desarrolladas durante el curso de Estructuras de Datos y Algoritmos. Cada proyecto se enfoca en la implementación práctica de una estructura de datos o un algoritmo fundamental, generalmente utilizando el lenguaje C.

---

## Listado de Actividades Desarrolladas (ADAs)

| ADA | Tema Principal | Descripción Breve | Directorio |
| :---: | :--- | :--- | :---: |
| **01** | Analizador de Expresiones | Conversión de expresiones infijas a **postfijas** (RPN) y su evaluación utilizando la estructura **Pila (Stack)**. | [Enlace al Directorio](<https://github.com/FernandoCardos/Portafolio-EstructuraDeDatos2025/tree/main/ADA01>) |
| **02** | Simulación de Colas | Simulación de atención en un banco con tres **Colas (Queue)**. Se calcularon métricas de eficiencia y tiempo de espera promedio. | [Enlace al Directorio](<https://github.com/FernandoCardos/Portafolio-EstructuraDeDatos2025/tree/main/ADA02>) |
| **03** | Lista Doblemente Ligada | Implementación de una **Lista Doblemente Ligada** a partir de un archivo CSV para realizar operaciones CRUD y búsquedas complejas de películas. | [Enlace al Directorio](<https://github.com/FernandoCardos/Portafolio-EstructuraDeDatos2025/tree/main/ADA03>) |
| **04** | Árbol Binario de Búsqueda (ABB) | Desarrollo de un sistema de gestión de estudiantes usando un **ABB** ordenado por matrícula. Incluye funciones avanzadas de reporte y travesía.

##Desarrollo

Todos los proyectos fueron desarrollados primariamente en lenguaje **C**, con un enfoque en el uso correcto de `structs`, punteros y recursividad para manipular eficientemente las estructuras de datos.
